How the tensile curve is computed

  1. σLY = σ0 + σss + σ*(T, v) + kyd−½

    Lower yield stress. Lattice friction, solid solution, thermal (Peierls) term, and Hall–Petch grain-boundary term.

  2. σ* = σ̂ [1 − (kT ln(v0/v) / ΔG0)2/3]2

    Thermally activated glide (Kocks form) of screw dislocations in bcc iron.

  3. ε̇ = φ b ρm v

    Orowan relation. With few mobile dislocations, each must glide faster, needing higher stress.

  4. Δσ = σ*(vUY) − σ*(vLY) + Δσlock

    Yield drop (Johnston–Gilman + Cottrell unlocking). Multiplication to ~1013 m−2 lowers the needed velocity and stress.

  5. θ = ceU/kT / (1 + ceU/kT)

    Atmosphere occupancy (Langmuir–McLean). Locked fraction f = θ(1 − e−c/5 ppm); ky = 0.25 + 0.45f MPa·m½.

  6. vfront = ε̇ L0 / (nf εL)

    Band front speed. Deformation is localized at the fronts sweeping the 50 mm gauge.

  7. σ = σLY + H∞(1 − e−(ε−εL)/εc), σρ = αMμb√ρ

    Work hardening (Voce / Kocks–Mecking) after bands unite; Taylor relation tracks dislocation density.

  8. σf ky √d = βμγ(T) = 0.34 eT/90 K MPa²·m

    Cleavage (Cottrell–Petch). Below the DBTT, cleavage intervenes before Lüders bands can form.
